# 中文／國文／台文系每日資訊站

目前完成 Stage 4：首頁前端骨架、搜尋／篩選，以及每日筆記的新增、編輯與刪除功能。

## 檔案用途

- `index.html`：網站首頁；讀取 JSON 資料，依序顯示最新論文／消息與每日筆記。
- `notes.json`：每日筆記的範例資料，共三筆，涵蓋中文系、國文系、台文系。
- `papers.json`：論文／消息的範例資料，共三筆，涵蓋三個領域。
- `note_editor.py`：本機筆記工具；提供網站並讓新增筆記表單能安全寫入 `notes.json`。
- `.gitignore`：排除 Python 快取與個人編輯器設定，避免不必要的檔案被提交。

## 如何執行

不要直接雙擊 `index.html`，因為瀏覽器通常會阻擋它讀取同資料夾的 JSON 檔。需要先安裝 Python 3（只用來啟動本機筆記工具，不是本專案的額外套件）。安裝後，請在本專案資料夾開啟 PowerShell，執行：

```powershell
python note_editor.py
```

接著在瀏覽器開啟 `http://127.0.0.1:8000`。停止工具時，在 PowerShell 按 `Ctrl + C`。

## 如何測試

1. 確認上方有三張論文／消息卡片，下方有三張每日筆記卡片。
2. 確認每張卡片都有日期、領域與標籤。
3. 確認「最新論文／消息」區塊位在「每日筆記」區塊上方。
4. 在關鍵字搜尋輸入 `詩經`，確認只留下相關的筆記與論文。
5. 將「領域」選為 `台文系`，確認只顯示台文系資料；再選取「標籤」測試交叉篩選。
6. 在「新增今日筆記」填入內容、領域與以逗號分隔的標籤，按下「儲存筆記」；確認新卡片立刻出現在筆記列表最上方。
7. 重新整理頁面，確認新筆記仍存在，表示已寫入 `notes.json`。
8. 按任一筆記的「編輯」，確認表單已帶入原本資料；修改後儲存，重新整理仍保留修改結果。
9. 按任一筆記的「刪除」，先確認提示內容，按下取消應保留資料；再次刪除並確認，該筆資料應消失，重新整理後也不會回來。
